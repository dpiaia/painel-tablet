# Ícones de marca

Ícones que aparecem depois do nome, na barra do topo, conforme o tema. O painel
procura `<slug-do-tema>.png` aqui — `orkut.png` para o tema Orkut, e assim por
diante. Sem o arquivo, o tema usa o sufixo de texto que estiver no código.

Não vão para o git: são ícones de terceiros, e este repositório é MIT.
